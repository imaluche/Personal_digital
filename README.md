## Ejecucion del programa
### El arranque se buscara que sea a parte de cada uno de los juegos, para facilitar el desarrollo
### la totalidad de las operaciones matematicas y logicas son llevadas por la "cpu" mientras lo graficos son dibujados en el display por medio de la "gpu"
### Se definirían espacios para poder comunicarse entre equipos sobre aspectos necesarios
### se necesita que el programa sea capaz de identificar el controlador y en el caso del teclados ser capaz de identificar los valores que si vale la pena declarar como variables para evitar uso innecesario de memoria
